# Nmap Network Scanning

## Objective

This project documents my practical learning and use of Nmap for network reconnaissance and security assessment.

## Tools Used

- Nmap
- Kali Linux

## Skills Practiced

- Host discovery
- Port scanning
- Service enumeration
- Understanding open ports
- Basic network reconnaissance

## Ethical Considerations

All scanning activities in this project are performed only against systems that I own or have explicit permission to test.
